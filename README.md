# ساهر — منصة أولية لتوليد الفيديو

مشروع عربي موجّه للهاتف لتجميع واجهة بسيطة فوق محركات توليد فيديو قابلة للاستبدال. **هذه بداية معمارية واختبار تكامل وليست خدمة إنتاجية ولا توليداً مجانياً غير محدود.** يبقى دفتر Colab الحالي لـ Wan2.1 كما هو، بينما يضيف المسار الجديد واجهة ويب عربية ومحّولاً أولياً إلى ComfyUI API.

## لماذا لا ندمج كل المشاريع داخل المستودع؟

أحجام النماذج واعتمادياتها وشروط أوزانها تختلف، وبعضها غير ملائم للتشغيل داخل Colab المجاني أو متصفح الهاتف. لذلك يحتفظ ساهر بواجهة موحدة ومحولات منفصلة، ويعمل التوليد على خادم GPU خاص أو مستضاف. لا ننسخ شيفرة أو أوزان المشاريع الخارجية إلى هذا المستودع.

- **واجهة وتجربة الهاتف:** صفحة ويب عربية خفيفة لإرسال النص ومتابعة الحالة ومعاينة الفيديو.
- **تكامل النسخة الأولى:** محول ComfyUI API يرسل النص إلى workflow اختاره المشغّل، ثم يستعلم عن حالة المهمة ويعرض مخرجاته.
- **التجارب الحالية:** دفتر Colab الموجود `Saher_Wan2.1_Text_to_Video.ipynb` لمسار Wan2.1 T2V-1.3B، بصورة مستقلة عن API.
- **المعالجة اللاحقة:** مكان مخصص لاحقاً لتمرير النتائج عبر FFmpeg. لم ندمج Real-ESRGAN أو RIFE بعد؛ ترخيص الأوزان والآثار الجانبية وجودة كل مسار تحتاج اختبارات منفصلة.

## تشغيل الواجهة محلياً

يتطلب المسار الجديد Python 3.10 أو أحدث وخادماً ComfyUI يمكن الوصول إليه من البيئة نفسها. لا يلزم تثبيت ComfyUI في الهاتف.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
export COMFYUI_BASE_URL=http://127.0.0.1:8188
export COMFYUI_WORKFLOW_PATH=/absolute/path/to/workflow-api.json
export COMFYUI_PROMPT_NODE_ID=6
export COMFYUI_PROMPT_INPUT=text
uvicorn saher_video.app:app --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000` من المتصفح على الجهاز الذي يشغّل الخدمة. يجب تصدير workflow من ComfyUI بصيغة **API**، وضبط معرّف عقدة النص واسم حقل الإدخال المطابقين لذلك workflow. أرقام العقد وأسماؤها تختلف من workflow إلى آخر. مثال تهيئة آمن موضح في [دليل البدء السريع](docs/quickstart-ar.md).

## ما يعمل وما لا يعمل

توفّر النسخة الحالية إرسال وصف نصّي إلى ComfyUI، والتحقق من معرّف عقدة النص، ثم الاستعلام عن الطابور والسجل وجلب ملفات الإخراج. لا يوجد بعد رفع ملفات، اختيار نموذج تلقائي، مصادقة، عزل مستخدمين، طابور مهام داخلي دائم، إلغاء مهمة، سجل مستخدم، أو نشر عام آمن. لا نضمّن workflow افتراضياً لأن عقد النماذج ومساراتها تعتمد على تثبيت ComfyUI الخاص بك.

يمكن اختبار واجهة المحول دون بطاقة GPU:

```bash
pytest
```

لم يُجرَ توليد فعلي على GPU ضمن هذا المستودع أو جلسة التطوير. نجاح الاختبارات الوحدوية لا يثبت توافق workflow أو جودة أو سرعة النموذج على جهاز بعينه.

## اختيار المكوّنات

التوصية الحالية هي البدء بمسار ComfyUI كطبقة تكامل، واختبار محرك واحد فقط في بيئة GPU محددة. يظل دفتر Wan2.1 الموجود نموذجاً أولياً منفصلاً؛ أما المرشحون لتجربة لاحقة بعد تثبيت شروط الاستخدام والموارد فهم Wan2.2 TI2V-5B أو بديل مرخّص ومناسب. ليس هناك قرار بضم LTX-2 أو HunyuanVideo-1.5 أو SkyReels-V3 إلى تشغيل عام الآن؛ لكل منها شروط تتطلب مراجعة دقيقة.

راجع [المعمارية وخطة الاختبار](docs/architecture-ar.md) و[مصفوفة التراخيص الأولية](docs/licenses-ar.md) قبل اختيار أوزان أو نشر الخدمة.

## الخصوصية والأمان

الافتراضي هو الربط على `127.0.0.1`. لا تغيّر المضيف إلى عنوان عام ولا تفتح منفذ ComfyUI للإنترنت: لا تحتوي هذه النسخة على مصادقة أو حصص أو حدود تنفيذ أو حماية للملفات. استخدم بوابة مصادقة وشبكة خاصة وتخزيناً مضبوطاً قبل إتاحة الخدمة لمستخدمين آخرين. تجنب تمرير صور أو أصوات أشخاص من دون الأذونات اللازمة.
