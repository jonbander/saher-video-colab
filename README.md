# ساهر — منصة أولية لتوليد الفيديو

مشروع عربي موجّه للهاتف لتجميع واجهة بسيطة فوق محركات توليد فيديو قابلة للاستبدال. **هذه بداية معمارية واختبار تكامل وليست خدمة إنتاجية ولا توليداً مجانياً غير محدود.** يضيف المشروع واجهة ويب عربية ومحّولاً أولياً إلى ComfyUI API، مع دفاتر منفصلة لتجارب Wan2.1 على Colab وKaggle.

## لماذا لا ندمج كل المشاريع داخل المستودع؟

أحجام النماذج واعتمادياتها وشروط أوزانها تختلف، وبعضها غير ملائم للتشغيل داخل Colab المجاني أو متصفح الهاتف. لذلك يحتفظ ساهر بواجهة موحدة ومحولات منفصلة، ويعمل التوليد على خادم GPU خاص أو مستضاف. لا ننسخ شيفرة أو أوزان المشاريع الخارجية إلى هذا المستودع.

- **واجهة وتجربة الهاتف:** صفحة ويب عربية خفيفة لإرسال النص ومتابعة الحالة ومعاينة الفيديو، للاستخدام على استضافة تسمح بخدمة ويب.
- **تكامل النسخة الأولى:** محول ComfyUI API يرسل النص إلى workflow اختاره المشغّل، ثم يستعلم عن حالة المهمة ويعرض مخرجاته.
- **تجارب Colab:** دفتر `Saher_Colab_ComfyUI_Demo.ipynb` يختبر ComfyUI والمحرك من خلايا notebook نفسها، من دون واجهة ويب عامة أو Tunnel. أما `Saher_Wan2.1_Text_to_Video.ipynb` فيبقى تجربة Wan2.1 T2V-1.3B الأصلية.
- **تجربة Kaggle:** دفتر `Saher_Kaggle_ComfyUI_Demo.ipynb` يشغّل ComfyUI محلياً ويرسل الأوصاف من خلايا Kaggle، ثم يعرض MP4 في مخرجات الدفتر. لا يفتح صفحة ويب أو Tunnel.
- **المعالجة اللاحقة:** مكان مخصص لاحقاً لتمرير النتائج عبر FFmpeg. لم ندمج Real-ESRGAN أو RIFE بعد؛ ترخيص الأوزان والآثار الجانبية وجودة كل مسار تحتاج اختبارات منفصلة.

## تجربة Colab المجانية

افتح [دفتر Colab التجريبي](https://colab.research.google.com/github/jonbander/saher-video-colab/blob/feature/saher-mvp-foundation/Saher_Colab_ComfyUI_Demo.ipynb)، اختر GPU إن كان متاحاً، وشغّل الخلايا بالترتيب. يفحص الدفتر GPU، يثبت ComfyUI، ينزّل نموذج Wan2.1 T2V-1.3B وملفاته، ثم يرسل وصفاً من واجهة notebook عبر تطبيق Saher ويعرض الفيديو الناتج.

**هذه تجربة تفاعلية من واجهة Colab وليست موقعاً عاماً أو خدمة Android دائمة.** سياسة Google تقول إن GPU والمدة والحصص المجانية غير مضمونة، وقد تُنهي الجلسة عند استخدام واجهة ويب خارج الدفتر لإنشاء المحتوى. لذلك لا يعرض الدفتر منفذ ComfyUI أو Saher للعامة ولا ينشئ Tunnel. اقرأ [دليل Colab المجاني](docs/colab-free-ar.md) قبل البدء.

## تجربة Kaggle

نزّل وافتح [دفتر Kaggle التجريبي](Saher_Kaggle_ComfyUI_Demo.ipynb) في Kaggle، واختر GPU وفعّل Internet من إعداداته. عدّل قيمة `PROMPT` في خلية التوليد، ثم شغّل الخلايا بالترتيب. يتعامل المستخدم مع الدفتر فقط؛ معاينة الفيديو ورابط التنزيل يظهران ضمن مخرجاته. إتاحة GPU محدودة وليست مضمونة، وملفات الجلسة مؤقتة. راجع [دليل Kaggle](docs/kaggle-free-ar.md) للخطوات.

## تشغيل الواجهة محلياً

يتطلب المسار الجديد Python 3.10 أو أحدث وخادماً ComfyUI يمكن الوصول إليه من البيئة نفسها. لا يلزم تثبيت ComfyUI في الهاتف.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
export COMFYUI_BASE_URL=http://127.0.0.1:8188
export COMFYUI_WORKFLOW_PATH=/absolute/path/to/workflow-api.json
export COMFYUI_PROMPT_NODE_ID=6
export COMFYUI_PROMPT_INPUT=text
uvicorn saher_video.app:app --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000` من المتصفح على الجهاز الذي يشغّل الخدمة. يجب تصدير workflow من ComfyUI بصيغة **API**، وضبط معرّف عقدة النص واسم حقل الإدخال المطابقين لذلك workflow. أرقام العقد وأسماؤها تختلف من workflow إلى آخر. مثال تهيئة آمن موضح في [دليل البدء السريع](docs/quickstart-ar.md).

## ما يعمل وما لا يعمل

توفّر النسخة الحالية إرسال وصف نصّي إلى ComfyUI، والتحقق من معرّف عقدة النص، ثم الاستعلام عن الطابور والسجل وجلب ملفات الإخراج. لا يوجد بعد رفع ملفات، اختيار نموذج تلقائي، مصادقة، عزل مستخدمين، طابور مهام داخلي دائم، إلغاء مهمة، سجل مستخدم، أو نشر عام آمن. لا نضمّن workflow افتراضياً في خدمة الويب لأن عقد النماذج ومساراتها تعتمد على تثبيت ComfyUI؛ دفتر Colab التجريبي ينشئ workflow محدداً لـ Wan2.1 T2V-1.3B.

يمكن اختبار واجهة المحول دون بطاقة GPU:

```bash
pytest
```

لم يُجرَ توليد فعلي على GPU ضمن بيئة التطوير؛ يجب تشغيل دفتر Colab لتجربة GPU حقيقية. نجاح الاختبارات الوحدوية لا يثبت توافر GPU أو جودة/سرعة النموذج في جلسة بعينها.

## اختيار المكوّنات

التوصية الحالية هي البدء بمسار ComfyUI كطبقة تكامل، واختبار محرك واحد فقط في بيئة GPU محددة. دفتر Wan2.1 الموجود يبقى مثالاً تجريبياً؛ أما المرشحون لتجربة لاحقة فهم Wan2.2 TI2V-5B أو بديل مرخّص ومناسب. ليس هناك قرار بضم LTX-2 أو HunyuanVideo-1.5 أو SkyReels-V3 إلى تشغيل عام الآن؛ لكل منها شروط تتطلب مراجعة دقيقة.

راجع [المعمارية وخطة الاختبار](docs/architecture-ar.md)، و[مراجعة المشاريع](docs/project-review-ar.md)، و[مصفوفة التراخيص الأولية](docs/licenses-ar.md) قبل اختيار أوزان أو نشر الخدمة.

## الخصوصية والأمان

الافتراضي هو الربط على `127.0.0.1`. لا تغيّر المضيف إلى عنوان عام ولا تفتح منفذ ComfyUI للإنترنت: لا تحتوي هذه النسخة على مصادقة أو حصص أو حدود تنفيذ أو حماية للملفات. استخدم بوابة مصادقة وشبكة خاصة وتخزيناً مضبوطاً قبل إتاحة الخدمة لمستخدمين آخرين. تجنب تمرير صور أو أصوات أشخاص من دون الأذونات اللازمة.
