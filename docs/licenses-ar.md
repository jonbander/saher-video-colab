# التراخيص وشروط الاستخدام في نسخة الصور

هذه مراجعة فرز تقنية وليست استشارة قانونية. يلزم فحص ملفات الترخيص الفعلية للإصدار والملف الذي تستخدمه، ولا تعني إمكانية تنزيل الأوزان أن كل استخدام أو إعادة توزيع مسموح.

## المكونات الحالية

- **Saher:** شيفرة المشروع في هذا المستودع.
- **ComfyUI:** البرنامج المحرك خارج هذا المستودع، ويشير مستودعه إلى GPL-3.0. يتصل Saher به عبر HTTP API ولا يضمّن شيفرته. راجع الترخيص قبل توزيع ComfyUI أو تعديل نسخته.
- **Stable Diffusion 1.5 checkpoint:** الدفتر ينزّل `v1-5-pruned-emaonly-fp16.safetensors` من مستودع Comfy-Org، وهو تحويل FP16 لأوزان SD1.5 الأصلية. بطاقة النموذج تشير إلى `CreativeML OpenRAIL-M`. هذا الترخيص يتضمن شروط استعمال؛ لذلك المشروع لا يصف النموذج بأنه «بلا قيود»، ولا يتجاوز شروط صاحبه.
- **Comfy-Org workflow:** ملف JSON في المستودع يحدد عقد ComfyUI الأصلية، ولا يحتوي الأوزان.

## المقصود بـ«من دون حظر Saher»

لا توجد قائمة كلمات أو تصنيف محتوى إضافي في تطبيق Saher. يُمرَّر النص إلى checkpoint المحدد بعد التحقق من كونه بين 3 و4000 محرف لأسباب فنية. هذا لا يعطل شروط رخصة النموذج، أو سياسات Kaggle ومزودي GPU، أو القوانين المحلية. كما أن النموذج نفسه قد يفشل أو لا يطابق كل وصف.
