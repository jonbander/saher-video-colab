# البدء السريع

## 1. جهّز محركاً خاصاً

شغّل ComfyUI في بيئة خاصة يمكن الوصول إليها من خادم ساهر. ثبّت النموذج والعقد اللازمة داخل ComfyUI وفق شروط كل نموذج. لا تفتح واجهة ComfyUI أو API مباشرة على الإنترنت العام.

## 2. صدّر workflow بصيغة API

في ComfyUI، جهّز workflow نصاً إلى فيديو يعمل لديك، ثم صدّره بصيغة API واحفظ JSON في مسار محلي. لا تستخدم workflow واجهة المستخدم العادي؛ صيغة API هي التي يحتاجها المسار `/prompt`.

في JSON الخاص بـ API، ابحث عن العقدة التي تستقبل الوصف. مثال شكلي فقط:

```json
{
  "6": {
    "inputs": {
      "text": "اكتب الوصف هنا"
    },
    "class_type": "YourTextEncoder",
    "_meta": {"title": "Text prompt"}
  }
}
```

هذا المثال ليس workflow قابلاً للتوليد ولا يحدد نوع العقدة الفعلي. عرّف رقم العقدة واسم المدخل الفعليين من ملفك.

## 3. ثبّت ساهر وشغّله

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
export COMFYUI_BASE_URL=http://127.0.0.1:8188
export COMFYUI_WORKFLOW_PATH=/path/to/workflow-api.json
export COMFYUI_PROMPT_NODE_ID=6
export COMFYUI_PROMPT_INPUT=text
uvicorn saher_video.app:app --host 127.0.0.1 --port 8000
```

افتح `http://127.0.0.1:8000`. الخدمة ترسل نصاً فقط إلى محرك ComfyUI المُعدّ. تظل المهام في طابور ComfyUI، وتستعلم الواجهة كل 2.5 ثانية عن الحالة لمدة تصل إلى 15 دقيقة.

## استكشاف الأعطال

- إذا ظهرت `503`، فتحقق من مسار workflow ووجود الملف.
- إذا أخفق إرسال المهمة، تحقق من أن العقدة والمدخل المحددين موجودان في workflow API، وأن النموذج والعقد المخصصة مثبتة في ComfyUI.
- إذا تعذر الاتصال بالمحرك، تحقق من `COMFYUI_BASE_URL` والاتصال الشبكي الخاص.
- إذا اكتمل التوليد بلا ملف فيديو، تحقق من عقد حفظ المخرجات في workflow؛ قد تتطلب بعض workflows عقدة إخراج فيديو بعينها.
- اختبر على GPU متاح فعلياً. هذه الشيفرة لا تختار النماذج أو الذاكرة تلقائياً ولا تضمن تشغيل Colab المجاني.

## حدود السلامة

هذا النموذج الأولي بلا تسجيل دخول، لذا لا تستخدمه كخدمة عامة ولا كواجهة متعددة المستخدمين. يلتزم التطبيق افتراضياً بـ `127.0.0.1`، ولا تغيّر ذلك إلا خلف طبقة مصادقة وصلاحيات. لا تضع مفاتيح أو روابط خاصة في مستودع عام.
