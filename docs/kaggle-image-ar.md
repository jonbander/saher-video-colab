# تجربة توليد الصور في Kaggle

## الاستخدام

1. نزّل ملف [`Saher_Kaggle_Image_Demo.ipynb`](../Saher_Kaggle_Image_Demo.ipynb) من GitHub وافتح Kaggle Notebooks، ثم أنشئ دفترًا واستورد ملف `.ipynb`.
2. من Settings اختر **Accelerator → GPU** وفعّل **Internet**. يلزم الإنترنت لاستنساخ ComfyUI والمشروع وتنزيل النموذج.
3. شغّل الخلايا بالترتيب. تتحقق الخلية الأولى من وجود GPU وذاكرته قبل تنزيل النموذج.
4. في خلية التوليد عدّل قيمة `PROMPT` ثم نفّذها. يستدعي Saher الـAPI محلياً، ويرسل الوصف إلى ComfyUI، ثم يعرض صورة PNG ورابط تنزيل داخل خلايا الدفتر.
5. نزّل النتيجة إلى جهازك قبل إغلاق الجلسة، أو أضف ملف `/kaggle/working/saher-image.png` إلى مخرجات نسخة الدفتر. شغّل خلية إيقاف ComfyUI عند الانتهاء.

## لماذا لا تظهر صفحة ويب؟

التجربة مخصصة لتفاعل دفتر Kaggle: واجهة الإدخال هي خلية `PROMPT`، والنتيجة تظهر أسفلها. يشغّل ComfyUI على loopback محلياً لخدمة API فقط، ولا يفتح لوحة ComfyUI ولا واجهة Saher خارج الدفتر، ولا ينشئ Tunnel أو عنواناً عاماً. هذه الطريقة تفصل اختبار المحول والنموذج عن نشر موقع دائم.

## النموذج ووقت التوليد

يستخدم الدفتر checkpoint الرسمي `v1-5-pruned-emaonly-fp16.safetensors` من Comfy-Org Stable Diffusion 1.5، ودقة 512×512 و16 خطوة وصورة واحدة. الملف يقارب عدة غيغابايت؛ التوليد أخف من إنشاء فيديو ولكنه يظل معتمداً على GPU والحصة المتاحة. تُعرض مواصفات Kaggle للـGPU على أنها موارد متغيرة ومحدودة، لذلك قد تحتاج للانتظار أو قد لا تكون البطاقة متاحة.

## حدود الطلبات

لا يحتوي Saher على قائمة كلمات مخصصة تمنع فئات prompts؛ يمرر النص إلى المحرك ضمن طول تقني 3–4000 محرف. هذا لا يجعل الموديل أو الاستضافة بلا شروط ولا يضمن نجاح أو قبول كل صورة. رخصة النموذج CreativeML OpenRAIL-M، وسياسات Kaggle والقانون تنطبق كذلك. لا تستخدم النظام للتزييف أو صور أشخاص دون موافقة.

## استكشاف الأخطاء

- إذا تعذر الاستنساخ أو التنزيل، تحقق من تشغيل Internet.
- إذا لم يظهر GPU، راجع Accelerator ثم أعد المحاولة لاحقاً؛ التوفر غير مضمون.
- إذا توقف ComfyUI، افحص آخر السطور في `/kaggle/working/comfyui.log`.
- إذا لم تظهر صورة، تأكد من اكتمال تنزيل checkpoint وظهور `SaveImage` في سجل المهمة.
- إذا نفدت المساحة، أعد تشغيل الجلسة لحذف ملفاتها المؤقتة، ثم أعد الخطوات بعد التحقق من مساحة Kaggle المتاحة.

لم يُجرَ توليد GPU أثناء إعداد المستودع؛ شغّل الدفتر في حسابك لاختبار موارد Kaggle الفعلية.
